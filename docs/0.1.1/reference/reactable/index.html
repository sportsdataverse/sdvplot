sdvplot.reactable

reactable-py columns (pip install sdvplot[reactable]), ported from sdvplotR's reactable_sdv_* functions, plus reactablefmtr's cell formatters (data bars, color tiles and scales, pills, icons, merged columns, highlights, bubbles).

reactable_sdv_color_scalesA reactable column whose cell backgrounds are filled on a color scale, by a color column, or in team colors.

reactable_sdv_args​

reactable_sdv_args(
    name: str,
    *,
    mode: str = 'light',
) -> dict[str, Any]

The Reactable keyword arguments that make a table look like a registry or reactablefmtr theme.

Arguments​

NameTypeDescription
namestrA reactablefmtr theme or a registry id, as in reactable_sdv_theme.
modestr"light" or "dark", as in reactable_sdv_theme.

Returns​

dict — theme (a reactable.Theme), striped, highlight (always True), bordered (the theme draws column rules) and compact (its cell padding is 4 pixels or less). A reactablefmtr theme returns its own Theme with the other keys at reactable's defaults.

Raises​

  • InputError: (a ValueError) As reactable_sdv_theme.

Example​

import pandas as pd
from reactable import Reactable
from sdvplot.reactable import reactable_sdv_args

df = pd.DataFrame({"team": ["KC", "BUF", "BAL"], "wins": [12, 10, 9]})
Reactable(df, **reactable_sdv_args("wikipedia"))
Reactable(df, **reactable_sdv_args("datagolf", mode="dark"))

reactable_sdv_theme(
    name: str,
    *,
    mode: str = 'light',
    font_size: float | None = None,
    font_color: str | None = None,
    header_font_size: float | None = None,
    header_font_color: str | None = None,
    background_color: str | None = None,
    cell_padding: float | str | None = None,
    centered: bool = False,
    **theme_args: Any,
) -> reactable.models.Theme

One of reactablefmtr's 27 table themes, or any of the 122 surveyed registry themes (sdv_table_themes()).

A reactablefmtr name wins over a registry id. "espn", "fivethirtyeight" and "pff" are the reactablefmtr ports; the surveyed look of those sites is "espn-site", "fivethirtyeight-site" and "pff-site". A registry theme is built from its palette, fonts and sizes: the text, background, hairline, stripe and hover colors, the header label style, the body font and the cell padding.

Pass the result to Reactable(theme=...). (reactable.options.theme would set it for every table in the session, so the theme is returned rather than set.) The themes do not load a font: give reactable_sdv_frame(font=...) a Google font for that.

Arguments​

NameTypeDescription
namestrThe theme: "cerulean", "clean", "cosmo", "cyborg", "dark", "darkly", "default", "espn", "fivethirtyeight", "flatly", "hoverdark", "hoverlight", "journal", "lux", "midnight", "midnightblue", "minty", "no_lines", "nytimes", "pff", "sandstone", "sanfran", "slate", "spacelab", "sunrise", "superhero" or "void"; or a registry id such as "wikipedia", "datagolf" or "nejm".
modestr"light" (default) or "dark". A reactablefmtr theme has no dark variant, so "dark" is accepted only for the themes that are dark already ("cyborg", "dark", "darkly", "hoverdark", "midnight", "midnightblue", "slate", "superhero") and raises for the rest. A registry theme raises when it is light-only.
font_sizefloat | NoneThe body font size in pixels; None for the theme's.
font_colorstr | NoneThe body text color; None for the theme's.
header_font_sizefloat | NoneThe header font size in pixels; None for the theme's.
header_font_colorstr | NoneThe header text color; None for the theme's. "hoverdark" and "hoverlight" have none.
background_colorstr | NoneThe table background; None for the theme's (most light themes have none: the page shows).
cell_paddingfloat | str | NoneThe cell padding, pixels or a CSS string; None for the theme's.
centeredboolCenter cell content vertically (useful with images).
**theme_argsAnyThe theme's own extra arguments, by their reactablefmtr names: "nytimes" border_color, border_width; "sanfran" cell_color, cell_border_width, cell_border_color, pagination_color; "void" border_color, border_width, header_border_color, header_border_width.

Returns​

reactable.Theme — The theme.

Raises​

  • InputError: (a ValueError) If name is neither a reactablefmtr theme nor a registry id (close matches are named), mode is not "light" or "dark", mode="dark" is asked of a light theme, centered is not a bool, or an argument is not one the theme takes.

Example​

import pandas as pd
from reactable import Reactable
from sdvplot.reactable import reactable_sdv_theme

df = pd.DataFrame({"team": ["KC", "BUF", "BAL"], "wins": [12, 10, 9]})
Reactable(df, theme=reactable_sdv_theme("espn"))
Reactable(df, theme=reactable_sdv_theme("midnight", font_size=13, centered=True))
Reactable(df, theme=reactable_sdv_theme("wikipedia"))

NameTypeDescription
