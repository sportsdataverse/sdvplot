# Table themes

sdvplot ships 122 table themes, one per surveyed source (journals, libraries, finance and news sites, sports reference
sites, government and periodical tables), named after the source: `datagolf`, `basketball-reference`, `wikipedia`,
`nejm`. They come from one registry file that sdvplotR and sdvtables read too, so a name means the same table in every
language. Lookup order is the house themes, then the 27 reactablefmtr ports (bare names such as `espn`), then the
registry (`espn-site` is the site's own look).

```python
from sdvplot.great_tables import gt_theme_source
from sdvplot.itables import itables_sdv_theme
from sdvplot.plottable import plottable_sdv_theme
from sdvplot.reactable import reactable_sdv_theme

gt = gt_theme_source(gt, "datagolf")        # a great_tables GT
theme = reactable_sdv_theme("datagolf")     # a reactable.Theme
```

`plottable_sdv_theme` and `itables_sdv_theme` take the same id. Pass `mode="dark"` to the themes with a dark palette
(`native` was measured, `derived` was derived from the light palette); `mode="dark"` on a light-only theme raises,
naming three dark-capable themes in its category. The full gallery with inline previews and the call for every
library is at [plot.sportsdataverse.org](https://plot.sportsdataverse.org/guides/table-theme-registry).
